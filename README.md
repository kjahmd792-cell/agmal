# نظام الاستقبال — مركز السبا

واجهة استقبال لمركز سبا بالعربية (RTL): لوحة متابعة يومية، حجوزات مع دورة حياة الجلسة
والدفع، هدايا، عملاء، مختصون، غرف، مدفوعات، شكاوى، قائمة انتظار، تقارير وتقويم.

نسخة محلية كاملة من تطبيق `literate-spa-flow-go`، مبنية بواجهة React على خادم API محلي.

## التشغيل

```bash
docker compose -f docker-compose.base44.yml up -d
```

- الواجهة: `http://localhost:3000`
- الـ API: خدمة `api` داخل الشبكة، ويُمرَّر عبر بروكسي Vite على `/api`

للتشغيل خارج Docker:

```bash
npm install
npm run api   # خادم الـ API على المنفذ 4000
npm run dev   # واجهة Vite على المنفذ 3000 مع بروكسي /api
```

## الدخول

الوضع التجريبي: زر «دخول تجريبي بضغطة واحدة»، أو أي بريد وكلمة مرور.
الجلسة محفوظة في كوكي HttpOnly، والبيانات التجريبية تُزرع تلقائيًا عند أول تشغيل.

## البنية

- `src/` — واجهة React (Vite + Tailwind + React Router)
- `src/pages/` — صفحات المسارات (الرئيسية، الحجوزات، الهدايا، المزيد، التقارير، ...)
- `src/components/` — الهيكل العام ومكونات الواجهة المشتركة
- `server/` — Express API: مصادقة، حجوزات وتوفر المختصين والغرف، هدايا، مدفوعات، تقارير
- `server/store.js` — مخزن JSON مع بيانات تجريبية (فرعان، خدمات، مختصون، غرف، حجوزات...)

بيانات التشغيل محفوظة في مجلد `data/` (أو `DATA_DIR`)، ويمكن تصفيرها بحذف المجلد.
